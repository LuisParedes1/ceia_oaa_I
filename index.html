Operaciones de Aprendizaje Automático I

El objetivo de la materia es acercar a los alumnos los conceptos necesarios para desarrollar productos de software relacionados a Machine Learning y análisis de datos de una manera escalable y siguiendo buenas prácticas de programación. También se trabaja sobre las tareas operativas de Machine Learning (MLOps) con distintas herramientas para disponibilizar los resultados en ambientes productivos.

Evaluación

Un trabajo práctico final grupal (máximo 6 personas) que se entrega en dos partes: la primera en la clase 5 y la final 7 días después de la última clase.

  • Nivel local (6–8): implementar en local el ciclo de desarrollo del modelo hasta generar el artefacto entrenado, usando un orquestador.
  • Nivel en contenedores (8–10): desplegar el modelo con Airflow, MLflow, PostgreSQL, MinIO y FastAPI sobre Docker.

Base: amq2-service-ml · ejemplo de implementación · apunte

Requerimientos

  • Lenguaje: Python ≥ 3.10 (uv, Poetry, pip o Conda)
  • Librerías: MLflow, librerías de datos y ML, Jupyter
  • Herramientas: GitHub, Docker, Apache Airflow
  • IDE: VS Code o PyCharm Community

8 clases teórico-prácticas, con hands-on en la mayoría.
